# Human character credits

All character models and animations are by **Quaternius** (https://quaternius.com), released under
**CC0 1.0 Universal** (public domain):

- Universal Base Characters (heads, hairstyles)
- Modular Character Outfits – Fantasy (peasant and ranger outfits, recoloured in-game)
- Universal Animation Library (idle, walk, jog, sword attack, pistol aim, hit, death, and more)

Built into web-ready GLBs by `tools/build-humans.mjs`.
- Universal Animation Library 2 (climb-up, running leap, slide, knock-back), built into `anims2.glb`
  by `tools/build-parkour-anims.mjs`. The wall-climb, ledge-hang and shimmy clips are posed in-game
  (`src/entities/parkourClips.js`) on the same skeleton.
